# Hepatic ceramide as the peripheral origin of CNS inflammation — compendium

Reproducibility compendium for the manuscript:

> Hernández-Montiel, Á. *Hepatic Ceramide as the Peripheral Origin of
> CNS Inflammation: An In Silico Hypothesis Integrating Gut–Liver–Brain
> Signaling.* In preparation (2026). Version v5.3.

The manuscript `.tex` source is **not** part of this repository. This
repo contains the code, CSV outputs, and figure-generating scripts that
produce every result the manuscript cites.

## Key findings (v5.3)

1. **MOL3_EAE is not homogeneous.** The state identified by Falcão
   et al. (2019) distributes 48/50 between the *MOL2* and *MOL5/6*
   categories of Zheng et al. (2025). Decomposing it by the Zheng
   annotation reveals two functionally opposite subpopulations:

   | Subpopulation | B4GALT6⁺ (Late) | DamageScore (Late) |
   |---|---|---|
   | MOL3∩MOL2  | 16.6% | 0.061 |
   | MOL3∩MOL56 | 3.7%  | 0.006 |

2. **The LacCer synthesis module survives the depth confound.**
   MOL2_like has +23% UMIs than MOL56_like (Wilcoxon p < 10⁻⁹⁰), which
   inflates the apparent B4GALT6 difference. However, the LacCer
   synthesis module (UGCG, B4GALT5, B4GALT6) remains significantly
   different after controlling for sequencing depth
   (coefficient = −0.163, p = 4.3×10⁻⁶), while the general
   sphingolipid synthesis and interconversion modules lose
   significance (p = 0.93 and p = 0.20, respectively). Figure 7.

3. **The depth caveat is explicit.** The B4GALT6 difference
   (16.6% vs 3.7%) is *apparent and consistent in direction*, but its
   *magnitude is partially confounded* with the higher RNA content of
   MOL2_like. Validation with FACS + qPCR normalised per cell (Aim 2)
   will quantify the biological component.

4. **Mdr2-KO produces more ceramide than EAE but does not cause CNS
   disease.** Smpd3 +4.80 vs +2.88, B4galt6 +3.77 vs +1.49. Only EAE
   induces Cers6 (the enzyme that produces Cer16:0, the pro-inflammatory
   species). This suggests that ceramide *species*, not total amount,
   distinguishes acute from chronic injury.

5. **S1PR1 is the dominant S1P receptor in the CNS.**
   S1PR1/S1PR3 ratio: 20× in astrocytes, 21× in microglia, 2.7× in
   neurons. Connects the axis to fingolimod (FTY720).

## Reproduce

    # 1. Install dependencies
    Rscript analysis/00_setup.R

    # 2. Download data (see data/README.md)

    # 3. Run analysis per layer
    for d in bulk cellular snrnaseq convergence; do
      for s in analysis/$d/*.R; do Rscript "$s"; done
    done

    # 4. Regenerate figures
    Rscript analysis/figures/F2_bulk_heatmap.R
    Rscript analysis/figures/F5_convergence_panel.R
    Rscript analysis/figures/S2_MOL3_expression.R
    # F1 is generated from a standalone TikZ source
    # F3, F4, F6 are generated by analysis/cellular/06_*.R and
    # analysis/snrnaseq/03_*.R and 07_*.R
    # F7 is generated by analysis/figures/F7_pathway_modules.R
    #   (see below) or by the standalone script scripts/51_pathway_MOL2_vs_MOL56.R


## H5 workflow (GSE250589)

The GSE250589 dataset (Zheng et al., 2025) provides 28 `.h5` files
(~30 GB total) with multiome counts (RNA + ATAC) for 131,881 cells.
Download instructions: see `data/README.md`.

**Why H5 files are not bundled:** 30 GB exceeds practical repository
limits. The raw H5 files were downloaded once, used to extract the CSVs
below, and then deleted to free disk space.

**Why they are not needed to reproduce the manuscript:** every
downstream analysis in `analysis/snrnaseq/` uses six precomputed CSVs
extracted from the H5 files. No downstream script reads H5 directly.

| Extracted CSV | Content | Generated by |
|---|---|---|
| `08_MOL3_sphingolipid_substructure.csv` | B4galt6+ fraction by MOL3 subpop x stage | `08_MOL3_sphingolipid_substructure.R` |
| `09_pathway_MOL2_vs_MOL56.csv` | Module means + Wilcoxon p per pathway | `09_pathway_MOL2_vs_MOL56.R` |
| `09_pathway_regression.csv` | Depth-controlled regression per pathway | `09_pathway_MOL2_vs_MOL56.R` |
| `10_expr_mat.csv` | 42 top-DE genes x 13,737 MOL3 cells (raw counts) | `10_ari_validation.R` |
| `10_labels.csv` | barcode + Zheng cellType + stage | `10_ari_validation.R` |
| `12_MOL3_subpop_profile.csv` | DamageScore + InterferonScore by subpop x stage | `12_MOL3_subpop_profile.R` |

**To re-extract additional genes or cells from raw data:**
1. Download the 28 H5 from GEO (accession GSE250589; see `data/README.md`)
2. Place them under `data/GSE250589/h5/`
3. Run `analysis/snrnaseq/10_ari_validation.R` (this is the only script
   that reads H5; it regenerates `10_expr_mat.csv` and `10_labels.csv`)
4. All other downstream scripts (`10b_*`, `11_*`) read CSVs only

## Reproducibility notes

- **34 R scripts** across four evidence layers (bulk, cellular, snrnaseq,
  convergence) plus figure-generation scripts.
- **62 CSV outputs** in `results/`, one folder per layer.
- **7 main figures** (F1–F7) and **4 supplementary figures** (S1–S4).
- **Environment**: R 4.3.x, Bioconductor 3.18, Seurat 5.0.x, DESeq2,
  fgsea, hdf5r, org.Mm.eg.db, cluster, vegan.
- **Version tag**: `v5.3` corresponds to the manuscript version with
  Figure 7 (pathway modules) and the depth confound caveat.
- **Confound**: MOL2_like has +23% UMIs than MOL56_like
  (Wilcoxon p < 10⁻⁹⁰). The LacCer module survives this confound
  (p = 4.3×10⁻⁶), but the B4GALT6 per-gene magnitude does not. The
  limitation is documented in the manuscript.
